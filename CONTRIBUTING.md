# Contributing

Contributions that improve simulator integration, display/input behavior, hardware documentation, or reliability are welcome.

## Guidelines

- Document the simulator, interface software, board, display, and firmware versions involved.
- Keep pinout, display, encoder, and protocol changes easy to reproduce.
- Do not commit credentials, private keys, tokens, or machine-specific secrets.
- Include reproduction steps for display, input, connection, or simulator-sync issues.
- Update documentation whenever supported hardware or dependencies change.

Pull requests should explain what changed, why it is useful, and how it was validated.
